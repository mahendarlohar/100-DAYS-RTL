## Objective
To design and verify seven basic logic gates using Verilog HDL.

## Gates Implemented
1. AND Gate
2. OR Gate
3. NOT Gate
4. NAND Gate
5. NOR Gate
6. XOR Gate
7. XNOR Gate

## Inputs
- A
- B

## Outputs
- Y_AND
- Y_OR
- Y_NOT
- Y_NAND
- Y_NOR
- Y_XOR
- Y_XNOR

## Design Approach
Implemented using Verilog continuous assignments
and bitwise operators.

## Testbench
A Verilog testbench was developed to verify
all seven logic gates.

## Test Cases
All four possible input combinations were tested:
- A = 0, B = 0
- A = 0, B = 1
- A = 1, B = 0
- A = 1, B = 1

## Simulation Tool
Xilinx Vivado

## Verification Result
All seven logic gates were verified successfully
for all four input combinations.

## Learning Outcomes
- Understood basic logic gate operations.
- Learned Verilog bitwise operators.
- Practiced RTL design.
- Learned testbench development.
- Observed simulation waveforms.
